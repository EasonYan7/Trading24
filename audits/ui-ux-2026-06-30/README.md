## 已按浏览器标注修正

- 侧栏导航已从 radio 改为普通导航按钮，并移除重复的“返回总览”大按钮。
- 管理页运行时间输入和“保存时间”按钮已改为同一行底部对齐。
- 当前标的已增加拖动排序组件，拖动后自动保存顺序。
- 每个标的已增加“编辑”和“删除”按钮；编辑面板支持修改名称、上限、下限、日涨跌幅，删除改为二次确认。
- 历史页已重设计为“摘要 + 运行记录 + 单条结论 + 完整报告折叠”的层级；标题显示不全、下拉框边界过浅、内容过多的问题已修正。
- 历史记录已支持先选择再删除，删除前必须二次确认；本次验证只进入确认流程，未执行真实删除。
- 管理页标题已从顶部小标签改为页面标题，并增加顶部留白，避免被 Streamlit 顶栏遮挡。
- 拖拽排序区已改为稳定容器：固定内边距、固定条目高度、用 gap 管理间距，减少鼠标停在条目之间时的 hover 抽动。
- 历史页增加“发给 AI”动作；右下角新增 AI 助手插件，可选择多条历史记录作为长文本附件，输入 prompt 后发送给模型，并在插件内查看本次对话历史。
- AI 助手优先调用 `DEEPSEEK_API_KEY` / `OPENAI_API_KEY` 对应的 OpenAI 兼容接口；没有模型密钥时会提示配置缺口，不伪造 AI 结论。
- 增加 `streamlit-sortables` 依赖，用于支持可返回排序结果的拖拽列表。

## 总体判断

当前版本已经具备可用的本地看板骨架：能扫读关注列表、进入详情看趋势和完整报告、查看历史、维护关注列表。最大问题不在功能缺失，而在信息层级、响应式布局、可访问性和防误操作。按“每天快速看一眼选股结果”的目标，当前界面还有偏重工程数据、偏轻用户决策的问题。

## 优先级问题

### P0 / P1：布局和可读性

1. 桌面 1280 宽下主内容被挤压，右侧指标卡在截图中被截断。左侧栏占比过大，主内容没有获得稳定宽度。
2. 移动端总览首屏只能看到 4 个指标卡和第一张股票卡的一半，真正的操作按钮在折叠下方，扫读效率偏低。
3. 详情页移动端直接展示完整 Plotly 图和报告折叠列表，对小屏用户过重；更适合先给“结论摘要 + 关键价格 + 风险点”，图表和全文作为次级内容。

### P1：按钮与交互

4. 管理页和历史页删除已补二次确认；剩余风险是删除后还没有撤销入口。
5. 侧栏重复“返回总览”已移除；详情页内仍保留返回按钮，后续可继续统一深层页面返回样式。
6. 历史页已改成摘要优先、完整报告折叠；后续还可继续把失败/运行中记录做成独立筛选或清理视图。
7. 侧栏 radio 已替换为普通导航按钮；仍需要继续检查键盘 Tab 顺序和读屏语义。

### P1：视觉一致性

8. Streamlit 自带的 Deploy / Main menu 顶栏可见，降低本地产品感；当前已通过增加顶部留白避免遮挡页面标题。
9. 图标字体修复不完整，DOM 和移动端可见 `keyboard_double_arrow_left`、`keyboard_arrow_right` 等文字或近似符号，影响专业感，也会干扰读屏。
10. 结构性 emoji 操作按钮已基本移除；页面图标和少量历史截图中的旧图标后续可继续统一为同一图标体系或纯文本命令。
11. 图表图例仍使用 BUY/SELL，而页面徽标使用“增持/中性/减持”，术语不统一。

### P1：可访问性与颜色

12. 浅灰辅助文字 `#9A958A` 在暖白背景上对比度约 2.75:1，在白卡上约 2.98:1，低于普通文本 4.5:1。
13. 主橙 `#FF5701` 在暖白背景上约 2.93:1，适合装饰或大号图形，不适合作为小文字唯一信息。
14. 图表 MA20 金色 `#C7A36A` 在暖白背景约 2.18:1，线条可读性偏弱。
15. 决策含义主要依赖红/绿/灰颜色；虽然徽标有文字，但图表点位和图例仍需要形状、中文标签、说明共同承载含义。

### P2：功能与信息架构

16. 总览卡片的“一句话结论”来自英文报告，未做中文化和稳定抽取，长句会撑高卡片，移动端尤其明显。
17. KPI 区显示“今日已分析/成本/增持/减持”，但数据库当前全是 2026-06-26 运行记录，标题“今日”可能误导；应按所选交易日或最新批次命名。
18. 管理页的运行时间只提供 `HH:MM` 标签，没有格式校验、时区说明、保存后的持久反馈。
19. 添加标的需要用户理解美股/A股/港股代码格式，当前只有 placeholder，没有常驻帮助或示例错误恢复路径。

## 建议改进顺序

1. 先修响应式骨架：桌面让主内容稳定占宽；移动端折叠侧栏，KPI 改成 2x2 紧凑或横向摘要条，股票卡首屏必须露出操作按钮。
2. 统一产品术语：全站用“增持 / 中性 / 减持”，图表图例和历史页同步中文化。
3. 管理页继续补维护细节：删除后增加撤销 toast；时间输入做更明确的格式校验；添加标的给常驻说明。
4. 修图标系统：去掉 emoji 和 Material 字体文字泄漏；尽量用 Streamlit 原生图标能力或纯文本命令。
5. 继续完善历史页：保留当前摘要优先结构，把失败/运行中记录进一步做成筛选或清理视图。
6. 优化图表：移动端隐藏 Plotly 工具栏或提供简化图；增加中文图例、数据摘要和表格替代信息。
7. 调整颜色 token：辅助文字加深，图表辅助线提高对比度，保证正文和标签满足可读性。

## 无法仅凭截图确认的事项

- 键盘 Tab 顺序、焦点环是否完整。
- 读屏器是否能正确读出 radio、select、expander、图表和 toast。
- 删除后的实际撤销能力目前不存在，但未执行真实删除。
- Streamlit 生产部署时是否可隐藏 Deploy / Main menu，需要结合运行配置验证。
